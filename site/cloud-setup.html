Your progress, wherever you practice.

PatternLab can keep drafts, attempts, hints, and study notes in your own Supabase project. Until it is connected, the app keeps saving privately in your current browser.

Connect the account service

  1. Create a Supabase project. Keep the database password private.
  2. Open SQL Editor in Supabase and run the PatternLab progress migration ↗. It creates the progress table and row-level security rules.
  3. In Authentication → URL Configuration, set the deployed PatternLab URL as the Site URL and add it to Redirect URLs: https://hdutee65.github.io/patternlab-dsa-practice/
  4. Copy the Project URL and the browser-safe publishable key (`sb_publishable_…`) from Project Settings → API.
  5. Add those two values to site/supabase-config.js on GitHub ↗, commit the change, and wait for Pages to republish.
  6. Choose Sign in / Create account on PatternLab. Confirm the email, then sign in on each device.

Security choices

The browser only receives the public publishable key. Each database row is protected by policies that require its owner to be signed in. Passwords go to Supabase Auth; PatternLab does not store them. Never put a secret or service-role key in this website.

For wider use, configure a trusted SMTP provider in Supabase. Its default email sender is intended for low-volume testing and may limit account confirmations.
